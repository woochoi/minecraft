# Mini Block World

Minecraft에서 영감을 받은 **1인칭 3D 복셀 샌드박스 웹 게임**입니다.
HTML5, CSS3, Vanilla JavaScript(ES6+)와 브라우저 내장 **WebGL API**만으로 만들었으며,
외부 라이브러리·빌드 도구·서버·이미지 파일 없이 `index.html` 하나를 열면 바로 실행됩니다.

**▶ 바로 플레이: https://woochoi.github.io/minecraft/** (데스크톱 Chrome 권장)

- 24 × 24 블록 크기의 자연스러운 언덕 지형 (잔디 / 흙 / 돌 지층 + 나무)
- 시드(Seed) 기반 지형 생성 → 같은 시드면 항상 같은 월드
- 블록 제거 / 설치, 중력·점프·충돌 처리
- localStorage 자동 저장, 새로고침 후 복구, 월드 초기화
- 한국어 픽셀 스타일 UI (시작 화면, HUD, 핫바, 일시정지 메뉴)

## 실행 방법

### 0) 웹에서 바로 실행
https://woochoi.github.io/minecraft/ 에 접속해 **GAME START** 를 누르면 됩니다.
(GitHub Pages 로 `main` 브랜치 루트가 배포됩니다. 시드 지정: `https://woochoi.github.io/minecraft/?seed=2024`)

### 1) 파일로 바로 실행
1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/woochoi/minecraft.git
   ```
2. `index.html` 을 **Chrome 최신 버전**으로 엽니다 (더블클릭 또는 드래그).
3. **GAME START** 버튼을 누르면 마우스가 잠기고 게임이 시작됩니다.

> ES 모듈 대신 일반 `<script>` 태그와 전역 네임스페이스(`window.MBW`)를 사용하므로
> `file://` 로 열어도 CORS/모듈 로딩 문제가 없습니다.

### 2) (선택) 로컬 웹 서버로 실행
```bash
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 을 엽니다.

### 시드 지정
주소 뒤에 `?seed=숫자` 를 붙이면 다른 지형이 생성됩니다. 시드마다 저장 데이터가 따로 관리됩니다.
```
index.html?seed=2024
```
기본 시드는 `1027` 입니다.

### 요구 사항
- WebGL 을 지원하는 데스크톱 브라우저 (Chrome 최신 버전 우선 지원)
- 마우스 (Pointer Lock API 로 FPS 방식 시점 조작)

## 조작법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` (방향키도 가능) | 앞 / 왼쪽 / 뒤 / 오른쪽 이동 |
| `Space` | 점프 (누르고 있으면 착지할 때마다 다시 점프) |
| 마우스 이동 | 1인칭 시점 회전 |
| 좌클릭 | 바라보는 블록 제거 (누르고 있으면 반복) |
| 우클릭 | 선택한 블록 설치 (누르고 있으면 반복) |
| `1` ~ `5` / 마우스 휠 | 블록 종류 선택 |
| `ESC` | 마우스 잠금 해제 + 일시정지 메뉴 |

### 블록 종류

| 키 | 블록 | 색상 / 무늬 |
|---|---|---|
| 1 | 잔디 (Grass) | 초록 윗면, 옆면 위쪽에 잔디 띠 |
| 2 | 흙 (Dirt) | 갈색 |
| 3 | 돌 (Stone) | 회색, 대비가 강한 노이즈 |
| 4 | 나무 (Wood) | 세로 줄무늬 껍질, 단면은 나이테 |
| 5 | 나뭇잎 (Leaves) | 어두운 점이 섞인 초록 |

### 게임 규칙
- 블록 조작 가능 거리는 최대 **5블록** 입니다.
- 플레이어 몸과 겹치는 위치에는 블록을 설치할 수 없습니다.
  - 단, **발이 있는 칸**에 설치하면 블록이 놓이고 플레이어가 그 위로 한 칸 올라섭니다(머리 위가 비어 있을 때).
  - 구멍을 파고 내려간 뒤에는 발밑을 보고 우클릭을 반복해 블록을 쌓으며 올라올 수 있습니다.
- 맨 아래 바닥층(y = 0)은 월드에 구멍이 나지 않도록 부술 수 없습니다.
- 월드 가장자리는 보이지 않는 벽으로 막혀 있습니다.

### 일시정지 메뉴 (ESC)
- **게임 계속하기**: 게임으로 복귀합니다.
- **월드 저장**: 현재 상태를 즉시 저장합니다. (블록 변경 후 1.5초가 지나면 자동 저장도 됩니다.)
- **월드 초기화**: 버튼을 두 번 누르면 저장 데이터를 지우고 처음 지형으로 되돌립니다.

> Chrome 은 ESC 로 마우스 잠금을 푼 직후 곧바로 다시 잠그는 것을 막습니다.
> "게임 계속하기" 후 "화면을 클릭하면…" 안내가 보이면 화면을 한 번 클릭하세요.

## 프로젝트 구조

```
mini-block-world/
├── index.html        # 페이지 뼈대, UI 요소, 스크립트 로드 순서
├── css/
│   └── style.css     # 픽셀 스타일 UI (패널, 버튼, HUD, 핫바, 애니메이션)
└── js/
    ├── blocks.js     # 전역 네임스페이스 MBW, 모든 상수(CONFIG), 블록 정의
    ├── renderer.js   # 벡터/행렬 연산, WebGL 셰이더, 청크 메시, 절두체 컬링, 조준 강조
    ├── world.js      # 시드 노이즈 지형·나무 생성, 블록 데이터, dirty 청크 관리
    ├── physics.js    # AABB 충돌 처리, Voxel DDA 레이캐스트
    ├── storage.js    # localStorage 저장 / 불러오기 / 검증 / 삭제
    ├── player.js     # 플레이어 위치·속도·시점·핫바 선택, 이동 규칙
    ├── input.js      # 키보드·마우스 입력, Pointer Lock
    ├── ui.js         # 시작 화면, HUD, 핫바 아이콘, 일시정지 메뉴, 알림
    └── main.js       # 진입점, 게임 상태 전환, 메인 루프, 블록 설치/제거
```

### 스크립트 로드 순서와 의존 관계
`index.html` 에서 아래 순서로 로드되며, 각 파일은 `window.MBW` 에 기능을 등록합니다.

```
blocks.js → renderer.js → world.js → physics.js → storage.js
          → player.js → input.js → ui.js → main.js
```

| 파일 | 등록하는 기능 | 사용하는 기능 |
|---|---|---|
| blocks.js | `MBW.CONFIG`, `MBW.BlockType`, `MBW.BLOCKS`, `MBW.HOTBAR_BLOCKS` | – |
| renderer.js | `MBW.Vec3`, `MBW.Mat4`, `MBW.Renderer` | CONFIG, BLOCKS |
| world.js | `MBW.World`, `MBW.createRandom` | CONFIG, BlockType |
| physics.js | `MBW.Physics` | CONFIG, Vec3 |
| storage.js | `MBW.Storage` | CONFIG |
| player.js | `MBW.Player` | Physics, Vec3 |
| input.js | `MBW.Input` | – |
| ui.js | `MBW.UI` | BLOCKS |
| main.js | `MBW.game` (디버깅용 게임 상태) | 위 모든 모듈 |

### 설계 원칙
- **역할 분리**: 플레이어는 입력 장치를 직접 읽지 않고 `main.js` 가 넘겨주는 이동 의도(`forward`, `right`, `jump`)만 사용합니다. 렌더러는 월드를 읽기만 하고 물리와 무관합니다.
- **상수 관리**: 블록 크기, 이동 속도, 점프력, 중력, 월드 크기 등은 모두 `js/blocks.js` 의 `MBW.CONFIG` 에 모여 있습니다.
- **외부 의존성 없음**: 행렬/벡터 연산, 노이즈, 블록 무늬를 모두 코드로 직접 구현했습니다.

### 주요 설정값 (`js/blocks.js`)

| 상수 | 기본값 | 설명 |
|---|---|---|
| `WORLD_SIZE_X` / `WORLD_SIZE_Z` | 24 | 월드 가로 / 세로 블록 수 |
| `WORLD_HEIGHT` | 32 | 최대 높이 |
| `CHUNK_SIZE` | 8 | 메시 청크 크기 |
| `MOVE_SPEED` | 4.6 | 이동 속도 (블록/초) |
| `JUMP_VELOCITY` | 8.2 | 점프 초기 속도 (약 1.3블록 높이) |
| `GRAVITY` | 26 | 중력 가속도 (블록/초²) |
| `REACH_DISTANCE` | 5 | 블록 조작 가능 거리 |
| `PHYSICS_STEP` | 1/120 | 고정 물리 시간 간격 |
| `DEFAULT_SEED` | 1027 | 기본 시드 |

## 동작 원리

### 게임 루프 (`main.js`)
`requestAnimationFrame` 마다 다음을 수행합니다.

1. 경과 시간(Delta Time) 계산 (탭 전환 등으로 튀는 값은 0.25초로 제한)
2. 마우스 이동량으로 시점 회전
3. **고정 간격(1/120초) 물리 업데이트** — 누적기 방식이라 FPS가 달라도 이동·점프 결과가 같음
4. 레이캐스트로 조준 블록 갱신
5. 변경된 청크 메시만 재생성
6. 물리 스텝 사이를 보간한 카메라로 렌더링
7. FPS(0.5초 평균), 좌표(0.1초 간격) HUD 갱신

게임 상태는 `TITLE → PLAYING ⇄ PAUSED` 로 전환되며, 포인터 잠금이 풀리면 자동으로 일시정지됩니다.

### 지형 생성 (`world.js`)
- 시드 기반 의사난수(mulberry32)와 **값 노이즈(Value Noise)** 를 4겹 합성한 프랙탈 노이즈로 지면 높이를 정합니다.
- 맨 위는 잔디, 그 아래 3층은 흙, 나머지는 돌로 채웁니다.
- 나무는 시드 난수로 위치를 정하고, 서로 4칸 이상 떨어지도록 배치합니다.
- 블록 데이터는 `Uint8Array` 하나에 저장하고, 생성 직후 상태(`baseBlocks`)를 따로 보관해 **사용자가 바꾼 블록만** 저장합니다.

### 복셀 렌더링 (`renderer.js`)
- 월드를 8 × 8 청크로 나누고, 청크마다 정점/인덱스 버퍼 하나로 통합해 그립니다.
- **보이지 않는 면 제거**: 이웃 칸이 비어 있는 면만 정점을 만들고, 블록끼리 맞닿은 내부 면은 버퍼에 넣지 않습니다.
- **부분 갱신**: 블록이 바뀌면 주변 1칸에 걸친 청크만 dirty 로 표시되어 그 메시만 다시 만듭니다.
- **절두체 컬링**: 카메라 시야 밖의 청크는 그리지 않습니다.
- **명암 표현**: 면 방향별 밝기, 정점 앰비언트 오클루전(AO), 거리 안개를 적용합니다.
- **절차적 무늬**: 텍스처 이미지 없이 프래그먼트 셰이더가 UV를 16 × 16 픽셀로 나눠 블록별 무늬를 만듭니다.
- 투영 행렬과 뷰 행렬(`lookAt`)은 직접 구현한 `Mat4` 로 계산하고, 깊이 테스트와 뒷면 제거를 사용합니다.

### Ray Casting (`physics.js`)
**Voxel DDA**(Amanatides & Woo) 알고리즘을 사용합니다.

1. 눈 위치가 속한 칸에서 시작합니다.
2. x · y · z 각 축에 대해 "다음 격자 경계까지의 거리(`tMax`)"와 "한 칸을 건너는 거리(`tDelta`)"를 계산합니다.
3. `tMax` 가 가장 작은 축으로 한 칸씩 이동하면서 광선이 지나는 칸을 정확한 순서로 방문합니다.
4. 처음 만나는 블록을 5블록 거리 안에서 찾습니다. 마지막으로 넘은 경계 방향이 **맞은 면의 법선**이 됩니다.
5. 제거는 맞은 블록을, 설치는 `맞은 블록 + 법선` 위치를 사용합니다.

### 충돌과 중력 (`physics.js`, `player.js`)
- 플레이어는 0.6 × 1.8 × 0.6 크기의 축 정렬 박스(AABB) 입니다.
- 매 물리 스텝마다 중력을 속도에 더하고(최대 낙하 속도 제한), **Y → X → Z 축 순서로 따로 이동**합니다.
- 이동 후 박스가 고체 블록과 겹치면 가장 가까운 블록 면에 붙여 멈추고, 그 축의 속도를 0으로 만듭니다.
- 아래로 이동하다 막히면 `onGround` 가 되어 점프할 수 있습니다.
- 축을 나눠 처리하므로 벽에 비스듬히 부딪혀도 벽을 따라 미끄러지듯 움직입니다.

### 저장 (`storage.js`)
- 키: `miniBlockWorld.save.v1.seed.<시드>`
- 형식: `{ version, seed, size: [X, Y, Z], savedAt, changes: [x, y, z, type, ...] }`
- 블록을 바꾸면 1.5초 뒤 자동 저장되고, 페이지를 떠날 때도 저장됩니다.
- 불러올 때 버전, 시드, 월드 크기, 좌표 범위, 블록 ID를 검사합니다. 하나라도 맞지 않으면 손상된 데이터로 보고 삭제한 뒤 기본 월드로 시작합니다.

## 디버깅
개발자 도구 콘솔에서 `MBW.game` 으로 게임 상태를 확인할 수 있습니다.

```js
MBW.game.player.position       // 플레이어 발 위치
MBW.game.target                // 현재 조준 중인 블록
MBW.game.renderer.stats        // 청크 수, 화면에 그린 청크 수, 삼각형 수
MBW.game.world.getChanges()    // 원본 대비 변경된 블록 목록
```
